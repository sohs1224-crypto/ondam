# 온담 (OnDam)

학생들이 익명으로 고민을 나누고 서로에게 온기를 전하는 공간.

- 프론트엔드: 정적 파일 (Vercel)
- 백엔드: Supabase (인증 + 데이터베이스)

## 파일 구성

| 파일 | 담당 |
|---|---|
| `index.html` | 뼈대 |
| `styles.css` | 디자인 전체 |
| `supabase.js` | 서버 통신 |
| `app-1-core.js` | 데이터·아이콘·공통 |
| `app-2-screens.js` | 홈·고민광장 화면 |
| `app-3-detail.js` | 상세·학교생활 |
| `app-4-actions.js` | 버튼 동작·로그인 |
